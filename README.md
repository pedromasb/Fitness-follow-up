# Move · Diario de ejercicio

PWA sencilla para apuntar cada día el ejercicio que haces (Fútbol, Gym, Pádel u Otro) con notas,
y ver tu historial en un mapa de calor estilo GitHub.

- Sin servidor ni cuentas: los datos se guardan en el propio móvil (localStorage).
- Funciona sin conexión (service worker).
- Copia de seguridad: botones *Exportar / Importar copia* (JSON).

## Publicar
1. Fusiona esta rama en `main`.
2. En GitHub: **Settings → Pages → Source: GitHub Actions**.
3. La app quedará en `https://pedromasb.github.io/Fitness-follow-up/`.

## Instalar en el móvil
- **iPhone (Safari):** Compartir → *Añadir a pantalla de inicio*.
- **Android (Chrome):** menú ⋮ → *Instalar aplicación*.
